
## 5. ข้อบกพร่องที่พบและแก้แล้ว

### หน้าที่การทำงาน

| # | อาการ | สาเหตุ | การแก้ |
| --- | --- | --- | --- |
| BUG-1 | เปิดคำขอ/หน่วยงานของคนอื่นแล้ว **ค้างที่ spinner ตลอดไป** พร้อม toast แดง แยกไม่ออกว่าระบบแฮงก์หรือไม่มีสิทธิ์ | หน้ารายละเอียดคืน `<Spinner/>` ทุกกรณีที่ยังไม่มีข้อมูล ไม่ได้แยกกรณี 404 | เพิ่มสถานะ `notFound` และหน้า **"ไม่พบคำขอนี้/ไม่พบหน่วยงานนี้"** พร้อมปุ่มกลับ — แก้ทั้ง `components/dataset/DetailView.tsx` และ `components/organization/DetailView.tsx` |
| BUG-2 | ช่อง **คำสำคัญ** และ **ติ๊กยอมรับเงื่อนไข** ยังขึ้นขอบแดงค้าง แม้ผู้ใช้แก้ถูกแล้ว | สอง control นี้ไม่ได้ผ่าน `set()` จึงไม่มีใครล้าง `fields[...]` ให้ | แยก `clearError()` แล้วเรียกจาก `onChange` ของทั้งสอง |
| BUG-3 | PDF ที่ระบบสร้างมี **หน้าเปล่าแทรกทุกหน้า** | `footer()` วาดที่ `y=800` ซึ่งต่ำกว่าขอบล่าง PDFKit จึงแทรกหน้าใหม่ให้ | ปิด `margins.bottom` เฉพาะตอนวาด footer แล้วคืนค่า (แก้ครั้งเดียวได้ทั้งสองเส้นทาง) |

### การจัดแนวและความเรียบร้อยของหน้าจอ

| # | อาการ | สาเหตุ | การแก้ |
| --- | --- | --- | --- |
| UI-1 | **หัวตารางกับแถวไม่ตรงคอลัมน์กัน** ทั้งตารางหน่วยงานและตารางชุดข้อมูล (เหลื่อมกันถึง ~50px) | หัวตารางกับแต่ละแถวเป็น grid คนละอัน แต่ใช้คอลัมน์ `auto` ซึ่งคิดความกว้างจากเนื้อหาของตัวเอง หัวตารางมีคำว่า "สถานะ" ส่วนแถวมี badge ยาวกว่า จึงได้ความกว้างคนละค่า | เปลี่ยนคอลัมน์สถานะเป็นความกว้างคงที่ (`12rem` / `14rem`) ทั้งหัวตารางและแถว |
| UI-2 | ในหน้ารายละเอียด **ค่าดูต่ำกว่าป้ายเล็กน้อยทุกแถว** | ป้ายใช้ 14px ค่าใช้ 15px แต่ grid จัดแบบ stretch ไม่ได้อิงเส้นฐาน | เพิ่ม `sm:items-baseline` ให้แถวข้อมูลทั้งสองหน้า |

> ปัญหาการจัดแนวทั้งสองข้อมีตัวตรวจอัตโนมัติแล้ว (`align-check.mjs`) ถ้าใครแก้ template
> ของตารางแล้วทำให้เหลื่อมอีก จะถูกจับได้ทันทีโดยไม่ต้องนั่งดูด้วยตา

## 6. ข้อสังเกตที่ไม่ใช่ข้อบกพร่อง

- ภาพ preview PDF เป็นพื้นขาวใน screenshot เพราะ Chrome headless ไม่โหลดปลั๊กอินแสดง PDF
  — ตรวจแยกแล้วว่าไฟล์ที่ระบบสร้างเปิดได้ปกติ
- API ที่ตอบไม่ใช่ 2xx ระหว่างทดสอบมีเฉพาะที่ตั้งใจให้เกิด: `401 /api/auth/me` (ก่อนล็อกอิน),
  `401 /login` (A-01), `410 /invitation` (A-03, A-09), `400 /register` (A-05),
  `400 /verify-otp` (A-07), `400 /generate-form` (B-04, SIT-05) และ `404` (SIT-26)
