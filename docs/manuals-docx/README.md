# คู่มือผู้ทดสอบ ฉบับ .docx

ไฟล์ในโฟลเดอร์นี้คือคู่มือชุดเดียวกับ `docs/12-` ถึง `docs/15-*.md`
แต่จัดหน้าเป็นเอกสาร A4 พร้อมส่งให้ผู้ทดสอบเปิดด้วย Word หรือ LibreOffice

| ไฟล์ | เนื้อหา | จำนวนหน้า |
| --- | --- | --- |
| `12-tester-manual-overview.docx` | ภาพรวมและการเข้าใช้งาน | 12 |
| `13-tester-manual-journey-a.docx` | ผู้ดูแลระบบสร้างหน่วยงานและส่งคำเชิญ | 12 |
| `14-tester-manual-journey-b.docx` | หน่วยงานลงทะเบียนตัวเอง | 27 |
| `15-tester-manual-journey-c.docx` | ลงทะเบียนชุดข้อมูล | 35 |

**ต้นฉบับคือไฟล์ Markdown** ถ้าจะแก้เนื้อหา ให้แก้ที่ `docs/1[2-5]-*.md` แล้วสร้างไฟล์ .docx ใหม่
อย่าแก้ในไฟล์ .docx โดยตรง เพราะรอบถัดไปจะถูกเขียนทับ

## สร้างใหม่

```bash
unzip -o -d /tmp/sarabun ../../../assets/theme_ci_design/Font/Sarabun.zip
python3 docs/tools/manual-to-docx.py /tmp/sarabun      # รันจากรากของ checkout
```

ต้องมี `python-docx` (`pip install python-docx`) และ `Pillow`

## สิ่งที่ตัวสร้างจัดให้

- **ฟอนต์ Sarabun จาก `assets/theme_ci_design/Font/Sarabun.zip`** และ **ฝังลงไฟล์**
  (ECMA-376 §15.2.13 obfuscated font) เครื่องที่ไม่ได้ติดตั้ง Sarabun จึงยังเห็นถูกต้อง
  — ฝังไว้สี่หน้า: Regular / Bold / Italic / BoldItalic
- ตั้งฟอนต์และขนาดครบทั้ง `w:ascii`, `w:hAnsi` และ **`w:cs` / `w:szCs`**
  ซึ่งเป็นชุดที่ Word ใช้กับภาษาไทย ถ้าตั้งไม่ครบ ตัวอักษรไทยจะกลับไปใช้ฟอนต์ตั้งต้น
- A4 · ขอบบน/ล่าง 2.0 ซม. ซ้าย 2.2 ขวา 2.0 · ระยะบรรทัด 1.45 เท่า (วรรณยุกต์ไทยต้องการที่)
- หน้าปกแยก ไม่มีหัว/ท้ายกระดาษ · สารบัญของหัวข้อระดับบน · เลขหน้าที่ท้ายทุกหน้า
- **จัดชิดซ้ายทั้งเล่ม ไม่ใช่ชิดสองข้าง** เพราะภาษาไทยไม่มีช่องว่างระหว่างคำ
  การจัดชิดสองข้างจึงไปดึงช่องว่างรอบคำภาษาอังกฤษจนห่างผิดปกติ
- ภาพหน้าจอจัดกึ่งกลาง มีกรอบบาง ๆ พร้อมคำบรรยายใต้ภาพ และไม่ถูกตัดออกจากคำบรรยาย
- ตารางกำหนดความกว้างคอลัมน์ตามความยาวเนื้อหาจริง หัวตารางสีกรมท่าและ**ซ้ำทุกหน้า**
  เมื่อตารางยาวข้ามหน้า
- อีโมจิที่ฟอนต์เอกสารไม่มี (⚠️ ✅ 🎉) ถูกแทนด้วยสัญลักษณ์ขาวดำที่มีจริง
  ไม่งั้นตัวอักษรจะหายไปเงียบ ๆ ตอนแปลง
